# Colors And Backgrounds

## What It Means

Colors and backgrounds define visual hierarchy, state, branding, and contrast.

## Diagram

```text
primary color   main action
neutral color   surfaces and borders
success color   approved state
warning color   pending state
error color     failed state
```

## Important Properties

```css
color
background-color
background-image
border-color
box-shadow
```

## Resume-Based Example

In onboarding screens, colors should clearly distinguish approved, pending, and rejected states without relying on color alone.

## Interview Answer

I use colors through tokens or variables, check contrast, and pair color with text or icons so the UI remains accessible.
