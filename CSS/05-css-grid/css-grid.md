# CSS Grid

## What It Means

CSS Grid is a two-dimensional layout system for rows and columns.

## Diagram

```text
+---------+---------+---------+
| card 1  | card 2  | card 3  |
+---------+---------+---------+
| card 4  | card 5  | card 6  |
+---------+---------+---------+
```

## Important Properties

```css
display: grid;
grid-template-columns
grid-template-rows
gap
grid-column
grid-row
```

## Resume-Based Example

Use Grid for dashboards, summary cards, admin panels, and responsive data overview screens.

## Interview Answer

I use Grid for two-dimensional page or dashboard layouts. Flexbox is better for one-dimensional alignment, while Grid is better for rows and columns.
