# CSS Interview Preparation Roadmap

This folder follows the same structure as the HTML folder. Each topic has:

- A topic-named `.html` file with a visual demo.
- A topic-named `.md` file with explanation, diagrams, interview notes, and resume-based examples.

## How To Run The Examples

Open any `.html` file directly in your browser, or use VS Code Live Server.

Example:

```text
CSS/04-flexbox/flexbox.html
```

## Recommended Study Order

1. CSS selectors and specificity
2. Box model
3. Display and positioning
4. Flexbox
5. CSS Grid
6. Responsive design
7. CSS units
8. Typography
9. Colors and backgrounds
10. Pseudo-classes and pseudo-elements
11. Transitions and animations
12. Forms, focus, and accessibility
13. CSS variables and theming
14. z-index and stacking context
15. CSS performance and architecture

## Resume-Based Focus

Your resume highlights React, TypeScript, Tailwind CSS, MUI, responsive design, Figma, accessibility, performance optimization, and enterprise onboarding flows. For interviews, connect CSS answers to:

- Pixel-perfect Figma implementation.
- Responsive dashboards and onboarding screens.
- Accessible focus and form states.
- Component-based styling in React.
- Maintainable styling using variables, utilities, and design tokens.
- Performance-friendly CSS and reduced layout shifts.
