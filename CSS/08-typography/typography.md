# Typography

## What It Means

Typography controls readable text: font family, size, weight, line height, spacing, and hierarchy.

## Diagram

```text
h1 page title
  h2 section title
    body text
    helper text
```

## Important Properties

```css
font-family
font-size
font-weight
line-height
letter-spacing
text-align
```

## Resume-Based Example

Pixel-perfect Figma work depends on matching heading hierarchy, body text, helper text, and error text.

## Interview Answer

Good typography improves readability and usability. I use clear hierarchy, accessible font sizes, comfortable line height, and consistent spacing.
