# Responsive Design

## What It Means

Responsive design makes a layout adapt to different screen sizes and devices.

## Mobile-First Diagram

```text
base styles: phone
min-width 768px: tablet
min-width 1024px: desktop
```

## Core Techniques

- Fluid layouts
- Media queries
- Relative units
- Flexible images
- Responsive typography

## Resume-Based Example

For banking, fintech, or onboarding applications, forms must work on desktop and mobile without hiding important actions or breaking validation messages.

## Interview Answer

I usually write mobile-first CSS, then add larger breakpoints using `min-width`. I test forms, tables, navigation, and action bars across device sizes.
