# Flexbox

## What It Means

Flexbox is a one-dimensional layout system. It arranges items in a row or column.

## Diagram

```text
main axis:      item -> item -> item
cross axis:     vertical alignment
```

## Important Properties

```css
display: flex;
flex-direction
justify-content
align-items
gap
flex-wrap
flex
```

## Resume-Based Example

Use Flexbox for onboarding step headers, action bars, toolbars, navigation, and aligning buttons inside MUI or custom React components.

## Interview Answer

I use Flexbox for one-dimensional layouts and alignment. It is ideal for toolbars, nav bars, button groups, and card headers.
