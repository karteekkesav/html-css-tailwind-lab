# Pseudo-classes And Pseudo-elements

## What It Means

Pseudo-classes style an element state. Pseudo-elements style a specific part of an element.

## Diagram

```text
pseudo-class:   button:hover
pseudo-element: button::after
```

## Examples

```css
button:hover {}
input:focus {}
input:disabled {}
.item:nth-child(odd) {}
.field::after {}
```

## Resume-Based Example

Use pseudo-classes for hover, focus, disabled, and validation states in onboarding forms. Use pseudo-elements for decorative markers or required indicators.

## Interview Answer

Pseudo-classes target states. Pseudo-elements target parts of elements or generated content.
