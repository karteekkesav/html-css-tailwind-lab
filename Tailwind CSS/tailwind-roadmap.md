# Tailwind CSS Roadmap

Use this roadmap for interview preparation and hands-on practice.

## Topics

1. Utility-first basics
2. Spacing, sizing, colors, and typography
3. Flexbox and Grid layouts
4. Responsive design and breakpoints
5. States, pseudo-classes, and variants
6. Forms, focus states, and accessibility
7. Customization, design tokens, and config concepts
8. Component patterns, reuse, and performance

## Recommended Practice Order

```text
utilities -> layout -> responsive -> states -> forms -> customization -> components
```

## Interview Focus

Be ready to explain:

- Why Tailwind is called utility-first CSS.
- How responsive prefixes like `md:` work.
- How hover, focus, disabled, and dark mode variants work.
- How to build reusable components without writing huge custom CSS files.
- How Tailwind removes unused CSS in production builds.
- When Tailwind is useful and when plain CSS or component library styles may be better.
