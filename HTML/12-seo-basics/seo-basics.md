# SEO Basics

## What It Means

SEO-friendly HTML helps search engines understand page content and purpose.

## Interview Answer

I improve SEO using a clear title, meta description, semantic HTML, correct heading hierarchy, descriptive links, image alt text, canonical URLs, and structured data where relevant. Performance and accessibility also support better user experience, which matters for SEO.

## Common Mistakes

- Missing title or duplicate titles.
- Multiple random `h1` headings.
- Links named "click here".
- Missing alt text for meaningful images.
- Poor semantic structure.

## Quick Revision

Good SEO starts with meaningful, structured, accessible HTML.
