# HTML Interview Preparation Roadmap

This folder is your HTML interview practice lab. Each topic has:

- A topic-named `.html` file you can open in the browser.
- A topic-named `.md` file with explanation, interview answer, mistakes, and revision points.

## How To Run The Examples

Option 1: Open the `.html` file directly in your browser.

Option 2: Use VS Code Live Server and open the topic HTML file.

Option 3: From the `HTML` folder, run a local server:

```bash
python -m http.server 5500
```

Then open the specific file URL in the browser.

1. Semantic HTML

3. Accessibility basics

8. Local Storage vs Session Storage
9. Cookies vs Local Storage
10. id vs class
11. Block, inline, and inline-block
12. SEO basics
13. HTML5 APIs
14. alt attribute
15. data attributes

## Interview Practice Method

For each topic:

1. Read the `.md` file.
2. Open the `.html` file.
3. Explain the concept aloud in 60 seconds.
4. Revise the matching Q&A in `html-interview-questions.md`.

For your Senior Frontend / ReactJS profile, focus especially on semantic HTML, accessibility, forms, ARIA, SEO, and script loading because these connect strongly to enterprise UI development.
