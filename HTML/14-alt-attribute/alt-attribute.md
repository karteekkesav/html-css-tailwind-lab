# alt Attribute

## What It Means

The `alt` attribute provides alternative text for images.

## Interview Answer

The `alt` attribute helps screen reader users understand image content and provides fallback text if an image cannot load. Informative images need meaningful alt text. Decorative images should use empty alt text, `alt=""`, so assistive technologies can skip them.

## Common Mistakes

- Missing `alt` on meaningful images.
- Using file names as alt text.
- Writing "image of" unnecessarily.
- Giving decorative images noisy alt text.

## Quick Revision

Alt text should communicate the purpose of the image.
