# id vs class

## What It Means

`id` identifies one unique element. `class` groups elements that share styling or behavior.

## Interview Answer

An `id` should be unique in a document and is often used for labels, anchors, and element relationships. A `class` can be reused on multiple elements and is commonly used for styling and reusable behavior.

## Common Mistakes

- Reusing the same `id` multiple times.
- Using IDs for every style.
- Forgetting `for` and input `id` relationships in forms.

## Quick Revision

One unique element: `id`. Many reusable elements: `class`.
