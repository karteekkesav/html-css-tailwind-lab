# div vs Semantic Tags

## What It Means

`div` is a generic block-level container. Semantic tags have meaning.

Examples:

- `nav` means navigation.
- `main` means primary page content.
- `footer` means footer content.
- `article` means self-contained content.

## Interview Answer

The difference is meaning. A `div` only groups content, while semantic tags describe the purpose of that content. I use semantic tags when the content has a clear role and use `div` only for layout or grouping when no semantic element fits.

## Common Mistakes

- Using `div` for navigation instead of `nav`.
- Using `div` for buttons instead of `button`.
- Using semantic tags only for styling.

## Quick Revision

Use semantic tags for meaning. Use `div` for neutral grouping.
