# HTML5 APIs

## What It Means

HTML5 APIs are browser features that allow web applications to do more than render static documents.

## Examples

- Web Storage API
- Geolocation API
- Canvas API
- Drag and Drop API
- History API
- File API
- Media APIs
- Web Workers

## Interview Answer

HTML5 APIs provide browser-native capabilities such as storage, location, graphics, file handling, media, and background processing. I use them depending on product needs, while considering permissions, privacy, performance, and browser support.

## Quick Revision

HTML5 APIs turn the browser into an application platform.
