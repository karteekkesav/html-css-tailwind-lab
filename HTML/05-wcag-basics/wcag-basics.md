# WCAG Basics

## What It Means

WCAG stands for Web Content Accessibility Guidelines. It provides standards for making digital content accessible.

## POUR Principles

- Perceivable: Users can perceive the content.
- Operable: Users can operate the interface.
- Understandable: Users can understand the content and actions.
- Robust: Content works with current and future assistive technologies.

## Interview Answer

WCAG is an accessibility standard based on POUR: Perceivable, Operable, Understandable, and Robust. In frontend work, this affects semantic HTML, keyboard support, color contrast, labels, error messages, focus handling, and screen reader compatibility.
