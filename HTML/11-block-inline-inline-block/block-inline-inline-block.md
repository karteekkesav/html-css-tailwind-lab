# Block, Inline, And Inline-block

## What It Means

These are display behavior concepts.

Block elements start on a new line and take available width.

Inline elements flow within text and do not behave like boxes with normal width and height.

Inline-block elements flow inline but accept width and height.

## Interview Answer

Block elements are used for larger layout structure, inline elements are used inside text flow, and inline-block is useful when an element should stay inline but still behave like a box.

## Quick Revision

Block breaks line. Inline stays in line. Inline-block stays in line and accepts box dimensions.
