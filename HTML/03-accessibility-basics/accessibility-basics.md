# Accessibility Basics

## What It Means

Accessibility means building web experiences that people with different abilities can use, including people using keyboards, screen readers, zoom, captions, or assistive technologies.

## Interview Answer

I improve accessibility by using semantic HTML, proper labels, meaningful alt text, keyboard-friendly controls, visible focus states, correct heading hierarchy, sufficient color contrast, and ARIA only when native HTML is not enough.

## Common Mistakes

- Making clickable `div`s instead of buttons.
- Removing focus outlines.
- Using placeholder text as the only label.
- Skipping alt text.
- Using headings for visual styling instead of structure.

## Quick Revision

Accessibility starts with correct HTML before CSS or JavaScript.
